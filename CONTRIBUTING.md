# Contributing to HotRestart

## License of your contribution

HotRestart is under the [MIT License](LICENSE). By sending a pull request, you agree that your contribution is under that license too, and that you have the right to contribute it.

You keep the copyright to your work. Your name stays in the git history.

## Code from elsewhere

Only add code or files you wrote, or ones under a license that allows it. If you copy from another project:

- Say where it came from in the pull request.
- Add its license and author to [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

MIT, BSD, Apache-2.0 and Zlib are fine. Ask in an issue first about anything else, such as GPL or code with no license.

## Before you send it

- `fvm flutter analyze` and `fvm flutter test` pass.
- A change works on both Windows and macOS, or the pull request says what you couldn't test.
- The README is updated if a feature changed.
